## 📌 Projects

- **Azure AI Cost Management** *(ongoing, team project)*: PowerShell scripts collect Azure VM cost, usage and performance metrics. AI analyses the data to recommend VM optimisations and cost savings, and Grafana dashboards visualise spend and recommendations.
- **Beowulf HPC Cluster** *(ongoing, Studio Operations Team)*: Part of the team supporting Otago Polytechnic's 15-node, Debian-based HPC cluster for student AI, ML and compute-heavy projects. The infrastructure is managed with Puppet, Hiera, r10k and GitHub Actions. I'm learning the setup and helping document the team's work in GitHub and a wiki.
- **Football Association Management System** *(client project)*: Full-stack web app built in an Agile Scrum team using SvelteKit, Node.js and Prisma, with role-based access control (RBAC).
